---
name: one-thing
description: Name the session's ultimate goal and the single lever that makes every other task easier or unnecessary.
disable-model-invocation: true
---

Name this session's ultimate goal, then find the **single thing** you can do right now toward it. Doing it should make the remaining work easier or unnecessary. Call this the **lever**. Pulling one lever first reaches the goal faster than working through the tasks in front of you one by one.

Pick exactly one lever. It must be something you can start right now. Explain why it is the lever in terms of the remaining work.

Then ask the user for the decisions needed to carry out the lever the way they intend. Carrying it out against their intent makes the lever add to the remaining work instead. In coding work, these decisions are mostly about CLI and function interfaces, key datatypes, and ownership and responsibility boundaries between modules.

Start on the lever only after the user answers.
